# TeachQuest Design System

This document outlines the design patterns, colors, typography, and components extracted from the existing TeachQuest web application. All new UI development must adhere to these standards to maintain consistency.

## 1. Typography
**Primary Font:** `Quantico`, sans-serif
- **Source:** Google Fonts (`https://fonts.googleapis.com/css2?family=Quantico:wght@400;700&display=swap`)
- **Usage:** Used universally for headings, body text, buttons, and inputs.
- **Weights:** 400 (Regular), 700 (Bold).

## 2. Color Palette

### Backgrounds
- **Global Page Background:** `#f4f7fa` (or `#f9f9f9`, `#E9ECEF`) - Light, clean gray/off-white.
- **Card/Container Background:** `#ffffff` (White).
- **Headers/Nav bars:** `#ffffff` (White).

### Text Colors
- **Primary Text:** `#000000` (Headings, Branding) or `#333333` (Body).
- **Secondary Text:** `#555555` or `#777777` (Subtitles, labels, timestamps).
- **Links/Accents:** `#007bff` (Standard Link Blue), `#0066FF`.

### Contextual Accents (Theme Colors)
The application uses specific color themes for different sections:

#### A. Dashboard Theme (Student/Teacher)
- **Primary Blue:** `#88D3EC` (Sky Blue) - Used for navigation buttons.
- **Secondary Blue:** `#98B4E8` (Periwinkle) - Used for table headers (`th`).
- **Action Teal:** `#5FE0D8` (Bright Teal) - Used for Logout button.
- **Hover/Active:** Slightly darker shades of the above.

#### B. Auth & Entry Theme (Login/Register/Selection)
- **Selection Mint:** `#D4F8E6` (Mint Green) - Used for role selection buttons.
- **Action Purple:** `#6200ee` - Used for primary "Register" buttons and input focus states.
- **Button Gray:** `#D9D9D9` - Used for "Login" buttons (hover: `#5a00d3`).

#### C. Job Portal Theme
- **Job Action:** `aqua` (Cyan) - Used for "Apply" buttons.
- **Hover:** `#3B8EA5`.

## 3. UI Components

### Containers & Cards
- **Style:** Clean white cards with soft shadows.
- **Border Radius:** `10px` (Standard) to `30px` (Large cards).
- **Shadow:** `0 4px 8px rgba(0, 0, 0, 0.1)` or `0 10px 30px rgba(0, 0, 0, 0.1)`.
- **Padding:** Generous padding (`20px` - `50px`).

### Buttons
- **Shape:** Rounded corners (`5px` standard) to Pill-shaped (`50px`).
- **Typography:** Bold (`font-weight: 700`), Centered.
- **Interaction:**
  - Hover: Background darkens or lifts (`transform: translateY(-3px)`).
  - Active: Background darkens further.
- **Common Classes (Ref):** `.btn`, `.role-btn`, `.apply-btn`, `.nav-btn`.

### Forms & Inputs
- **Inputs:**
  - Padding: `10px` - `12px`.
  - Border: `1px solid #ccc`.
  - Radius: `5px`.
  - Focus: Border color changes to `#6200ee` (Purple).
- **Labels:** `14px` - `16px`, color `#555`.

### Tables
- **Header:** Background `#98B4E8` (Periwinkle) or `#9AAEEF`. Bold, White or Black text.
- **Rows:** White background, `border-bottom: 1px solid #eee`.
- **Typography:** Bold, clean alignment.

## 4. Layout Patterns
- **Dashboard:**
  - Top fixed header (White, Shadow) containing Logo (Left) and User Controls (Right).
  - Main content area with "Nav Buttons" row followed by "Content Sections".
  - Content usually centered or max-width `1000px` - `1200px`.
- **Auth/Selection:**
  - Split layout (Illustration Left, Card Right) or Centered Card.
  - Responsive: Stacks vertically on smaller screens.

## 5. Icons
- **Usage:** Minimalist. Often used inside buttons or as status indicators.
- **Specifics:** Emoji icons (🎓, 👨‍🏫, 🔔) are used directly in code, or simple image icons (`.btn-icon`).
