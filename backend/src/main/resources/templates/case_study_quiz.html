Case Study: Database Optimization

Scenario

A large e-commerce platform 'ShopFast' is experiencing slow load times during peak hours. The engineering team has identified that the 'Product Search' query is the bottleneck. The database currently stores 10 million products. Users frequently search by 'Category' and sort by 'Price'.

The current query is: SELECT * FROM products WHERE category = ? ORDER BY price ASC. However, there are no composite indexes, only a single index on 'id'.

Based on the scenario, which indexing strategy would yield the best performance improvement for the search query?
A
Create separate indexes on 'category' and 'price'.
B
Create a composite index on (category, price).
C
Create a composite index on (price, category).
D
Cache all results in Redis without DB changes.
