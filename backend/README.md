# TeachQuest (AOOP)

This folder contains the previous TeachQuest application built with server-rendered HTML/CSS/JavaScript and Spring Boot.

## Run locally

Requirements: Java 17 and MySQL configured in `src/main/resources/application.properties`.

```powershell
.\mvnw.cmd spring-boot:run
```

The current React application lives in the parent `frontend/` folder. This legacy project is kept separate so it can be archived or uploaded independently.
